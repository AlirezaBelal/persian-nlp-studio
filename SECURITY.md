# Security policy

This is an intentionally simple static app: no backend, user accounts, database, network APIs, analytics, trackers or third-party runtime libraries. Text-derived UI content is inserted via `textContent`, not HTML.

The interface uses a restrictive Content Security Policy, including `connect-src 'none'`. The downloadable report includes numeric metrics only.

To report vulnerabilities, use GitHub's private vulnerability reporting if enabled; otherwise contact the maintainer privately rather than publishing exploit details or private user text.

Only the independent product's code is licensed or released here. Do not import unrelated academic coursework, trained model weights or third-party assets without review.
